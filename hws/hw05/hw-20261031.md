## Задача 1. «Первый — победил»

**Условие:** Сервису приходит 5 «запросов» (5 горутин). Приз один — забирает его только первый. Объявите `var prize atomic.Bool` и пусть каждая горутина «претендует» на приз вызовом `prize.CompareAndSwap(false, true)`; строку `Горутина N выигрывает` печатает **только** та горутина, чей вызов вернул `true`. После паузы `time.Sleep(time.Second)` программа завершается.

**Пример:**
```
Горутина 3 выигрывает
```
Ровно **одна** такая строка за прогон; номер N (1–5) любой — кто успел первым, случайно.

**Чему учит:** `atomic.Bool` и `CompareAndSwap` — флаг «первым пришёл — первым забрал» без блокировок (слайд 1).

**Подсказка:** *CAS вернёт `true` только тому, у кого значение было `false` **до** обмена: `if prize.CompareAndSwap(false, true) { … }`. Все остальные горутины получат `false` и просто пройдут мимо.*

**Ожидаемый результат:** `go run -race main.go` — без предупреждений; слово «выигрывает» в выводе встречается ровно один раз (проверьте несколько прогонов).

## Задача 2. «Уникальная регистрация»

**Условие:** 5 горутин каждая регистрируют **одни и те же** 20 слов `w0…w19` в общей `sync.Map`. `Register` возвращает `true`, только если слова в мапе ещё **не было** (первая регистрация). `main` накапливает количество первых регистраций в `registered atomic.Int64` и после паузы печатает итог. Заполните `Register` в шаблоне.

**Шаблон** (`main.go`):
```go
package main

import (
	"fmt"
	"sync"
	"sync/atomic"
	"time"
)

var (
	registered atomic.Int64
	words      sync.Map // слово -> true (зарегистрировано)
)

// Register: true, если слово зарегистрировано впервые.
func Register(w string) bool {
	// TODO: используйте words.LoadOrStore
	return false
}

func main() {
	for i := 0; i < 5; i++ {
		go func(id int) {
			for j := 0; j < 20; j++ {
				w := fmt.Sprintf("w%d", j)
				if Register(w) {
					registered.Add(1)
				}
			}
		}(i)
	}

	time.Sleep(time.Second)
	fmt.Println("registered:", registered.Load())
}
```

**Пример:**
```
registered: 20
```
Всегда 20: слов всего 20, и каждое «первое» ровно один раз — каким бы ни было переплетение горутин.

**Чему учит:** второй результат `LoadOrStore` (слайд 2): `loaded == true` — ключ уже был, вы ничего не записали.

**Подсказка:** *`_, loaded := words.LoadOrStore(w, true)` — ответ на «первая регистрация» это `!loaded`. Какое значение вы кладёте (`true`) — неважно, важен флаг.*

**Ожидаемый результат:** `go run -race main.go` — без предупреждений; число всегда 20.

## Задача 3. «Отчёт считается один раз»

**Условие:** Функция `computeTop3()` «дорогая»: она спит 200 мс, печатает `считаю… (дорого)` и возвращает слайс из трёх «топ-товаров». 8 горутин получают отчёт и печатают `Горутина N: <результат>`. Тело `computeTop3` должно выполниться **ровно один раз** — все горутины получают один и тот же готовый слайс. Используйте `sync.OnceValue` (Go 1.21+, упомянут в конце слайда 3). Шаблон сейчас считает отчёт 8 раз (прогнать можно) — поправьте его.

**Шаблон** (`main.go`):
```go
package main

import (
	"fmt"
	"time"
)

func computeTop3() []string {
	fmt.Println("считаю… (дорого)")
	time.Sleep(200 * time.Millisecond)
	return []string{"apple", "banana", "cherry"}
}

// TODO: сейчас тело считается 8 раз — заставьте его посчитать ровно один раз
var top3 = computeTop3

func main() {
	for i := 0; i < 8; i++ {
		go func(id int) {
			fmt.Printf("горутина %d: %v\n", id, top3())
		}(i)
	}

	time.Sleep(time.Second)
}
```

**Пример:**
```
считаю… (дорого)
горутина 1: [apple banana cherry]
горутина 4: [apple banana cherry]
… (всего 8 строк, порядок любой)
```
Строка `считаю… (дорого)` печатается **ровно один раз** — хотя вызовов восемь.

**Чему учит:** `sync.OnceValue` — «готовый» `sync.Once` для функции, которая считает один раз и запоминает результат (слайд 3).

**Подсказка:** *`sync.OnceValue(f)` возвращает функцию: первый вызов выполняет `f`, все следующие возвращают сохранённый результат. Замените `top3 = computeTop3` на `top3 = sync.OnceValue(computeTop3)` и добавьте импорт `"sync"`.*

**Ожидаемый результат:** `go run -race main.go` — без предупреждений; слово «считаю» в выводе встречается ровно один раз, строк `горутина` — восемь.

## Задача 4. «Почини гонку»

**Условие:** Программа «считает» очки: 20 горутин, каждая добавляет по 100 очков в общий `score`. Сумма может выйти **меньше** 2000 (и разной от прогона к прогону), а `go run -race` ловит гонку.

1. Прогоните программу с `go run -race main.go` и прочитайте отчёт детектора: на какой строке файла конфликт и какие операции (Read/Write) конфликтуют?
2. Почините код с помощью `sync/atomic` (слайд 1) так, чтобы сумма была ровно **2000** и `-race` не выдавал предупреждений.

**«Сломанная» программа** (`main.go` как есть):
```go
package main

import (
	"fmt"
	"time"
)

var score int

func main() {
	for i := 0; i < 20; i++ {
		go func() {
			for j := 0; j < 100; j++ {
				score++
			}
		}()
	}

	time.Sleep(time.Second)
	fmt.Println("score:", score)
}
```

**Чему учит:** чтение отчёта `-race` (слайд 4): какая строка, какие горутины, какие операции; и типичная гонка на `score++` — это «прочитать → добавить → записать», а не одна операция.

**Подсказка:** *Замените `var score int` на `var score atomic.Int64`, а `score++` на `score.Add(1)`. Гонка на строке `score++` — именно её и укажет детектор.*

**Ожидаемый результат:** после правки `go run main.go` печатает `score: 2000`, а `go run -race main.go` — без предупреждений.

## Задача 5. «Табло лидеров»

**Условие:** 10 игроков (`p1…p10`) с очками `10, 20, …, 100` «борются» за верхнюю строку табло. `leader atomic.Pointer[Player>` — пока пусто. Игрок становится лидером **только если** текущий лидер слабее (или лидера нет); иначе попытка безрезультатна. Используйте цикл CAS (слайд 1: `atomic.Pointer[T]` — «атомарная» замена ссылки). Заполните `tryWin` в шаблоне.

**Шаблон** (`main.go`):
```go
package main

import (
	"fmt"
	"sync/atomic"
	"time"
)

type Player struct {
	Name  string
	Score int
}

var leader atomic.Pointer[Player]

// tryWin: игрок выходит в лидеры только если текущий лидер слабее (или лидера нет).
func tryWin(p *Player) {
	// TODO: цикл CAS: leader.Load → сравнить → leader.CompareAndSwap;
	// если лидер поменялся под ногами — попробуйте снова
}

func main() {
	for i := 1; i <= 10; i++ {
		p := &Player{Name: fmt.Sprintf("p%d", i), Score: i * 10}
		go func() {
			tryWin(p)
		}()
	}

	time.Sleep(time.Second)
	l := leader.Load()
	if l == nil {
		fmt.Println("leader: (пусто) — заполните tryWin")
		return
	}
	fmt.Println("leader:", l.Name, l.Score)
}
```

**Пример:**
```
leader: p10 100
```
Лидер всегда `p10` (100 очков) — самого сильного обогнать нельзя.

**Чему учит:** `atomic.Pointer[T]` и цикл «прочитать → сравнить → обменять» с повтором (CAS) — классический «обнови рекорд, только если он лучше» без блокировок.

**Подсказка:** *Цикл `for`: `cur := leader.Load()`; если `cur != nil && cur.Score > p.Score` — текущий лидер сильнее, `return`; если `leader.CompareAndSwap(cur, p)` — вы победили, `return`; иначе лидера поменяли под вашими ногами — и цикл пробует снова.*

**Ожидаемый результат:** `go run -race main.go` — без предупреждений; результат всегда `leader: p10 100`.
